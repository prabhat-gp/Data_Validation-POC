Azure.
Network Access Control:

16. All access controls must follow the principle of least privilege.

17. Network Access Control (NAC) in network layer 4 (transportation) must be used to filter traffic within the architecture.

17.1. All ports and protocols not required for the application must be disabled.

17.2. Subnet level NSGs must enforce that only legitimate traffic can communicate between the tiers. An additional resource level NSG is recommended to further enforce access control within a subnet.

17.3. IaaS infrastructure:

17.3.1. The VM, VMAS or VMSS deployed as an IaaS model should be placed in a managed Azure VNET that forces traffic to go through HGS managed firewall infrastructure.
 
AWS.
 
Network Access Control:

19. Network Access Control (NAC) must be used to filter traffic within the architecture.

a. AWS Transit Gateway must be used for traffic routing between networks acting as a central hub.

b. All ports and protocols must be disabled by default. All connections must be configured for least privilege ports, protocols and IP addresses.

c. Security Groups must be implemented to allow that only legitimate traffic can communicate between tiers. Additional resource level Security Groups are recommended to further enforce access control on resources.

20. NAC rules, such as Security Groups, WAF and firewall rules must be managed by the HGS Firewall team.

a. Users are required to open firewall rule request for any additional traffic needed outside of default traffic.

b. AWS Network Manager must be used to provision Security Groups to all EC2 instances.

20. Network Address assignment for all AWS infrastructure is to be managed through InfoBlox IPAM.
